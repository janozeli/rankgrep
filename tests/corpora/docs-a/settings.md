# Settings

## All settings

Every setting below lives in the user settings file.

#### autosave

The autosave setting controls one part of the editor. Option 0 applies to every window.
Default value for autosave is chosen per platform.
Changing autosave takes effect after a restart.
Workspace settings override user settings.
Invalid values fall back to the default.
See the changelog for the history of autosave.
